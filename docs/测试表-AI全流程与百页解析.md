## E. 视觉 page_ocr（确认后才跑 · 控成本）

> 并发实锤：**每批 2 页图**（`OCRVisionBatch=2`）。  
> 例：10 个无字页 → 至少 5 个并发批次；积分预估 ≈ 页数 × `vision_points_per_page`。

| # | 步骤 | 期望 | 实测 | 状态 |
| --- | --- | --- | --- | --- |
| E0 | 余额与预估 | UI 展示无字页数与预估积分；**取消则 0 次视觉调用** | | ⬜ |
| E1 | 确认后启动 | 进度按页；失败页可继续其余页 | | ⬜ |
| E2 | 观察服务端 | 同时渲染/识别峰值约 2 页 | | ⬜ |
| E3 | 超过 `AI_DOC_MAX_OCR_PAGES` | 明确拒绝拆分，不静默截断 | | ⬜ |
| E4 | （P2 后）写回交易 | 视觉文本进入 `ql_transactions`，可核对 | | ⬜ |
| E5 | 与「智能解析」并行 | 全局分析槽仅 **2**；第三人应排队而非暗失败 | | ⬜ |

**本夹具建议：** 用 `2_`/`3_` 做小页数确认流即可；**不要**对 41 页工行无脑全开视觉。
