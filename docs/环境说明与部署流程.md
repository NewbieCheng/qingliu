# 部署与回滚

> 清流只有**一套生产环境**。测试不建在清流侧：AI 与解析能力的验证走不加班后端（no996 AI）。

---

## 一、环境

| 项 | 值 |
| --- | --- |
| 域名 | `https://qingliu.bujiaban.top` |
| 服务 | `qingliu.service` |
| 端口 | `127.0.0.1:8787` |
| 二进制 | `/opt/qingliu/qingliu` |
| 前端 | `/opt/qingliu/frontend/dist` |
| 配置 | `/etc/qingliu/qingliu.env` |
| 数据库 | `qingliu` |

> 清流自己没有测试环境。要在上线前验证 AI/解析行为，用不加班后端的能力与账号去测；需要完全隔离的环境时再按本文后面的「临时验证环境」临时起一套，用完即删。

## 二、一键部署（推荐）

```bash
./scripts/deploy.sh
```

脚本做的事：

1. 编译 linux/amd64 二进制与前端
2. 上传并用 sha256 双向校验，传输损坏直接中止
3. 备份现有二进制与前端（只保留最新一份）
4. 停服 → 替换 → 启服
5. 健康检查：`/health` 返回 200 才算成功，否则打印日志并退出
6. 收尾输出部署后的 sha256

## 三、手动部署（应急）

```bash
# 编译
cd server && CGO_ENABLED=0 GOOS=linux GOARCH=amd64 \
  go build -trimpath -ldflags="-s -w" -o /tmp/ql.bin .
cd ../frontend && pnpm build

# 上传
scp -i ~/.ssh/no996_prod_ed25519 /tmp/ql.bin root@115.191.68.41:/tmp/ql.bin
ssh root@115.191.68.41 "rm -rf /tmp/qd && mkdir -p /tmp/qd"
scp -i ~/.ssh/no996_prod_ed25519 -r frontend/dist/. root@115.191.68.41:/tmp/qd/

# 校验哈希（必须一致）
sha256sum /tmp/ql.bin
ssh root@115.191.68.41 "sha256sum /tmp/ql.bin"

# 替换（注意先停服，否则 Text file busy）
ssh root@115.191.68.41 '
  TS=$(date +%Y%m%d-%H%M%S)
  cp /opt/qingliu/qingliu /opt/qingliu/qingliu.bak-$TS
  systemctl stop qingliu.service
  cp /tmp/ql.bin /opt/qingliu/qingliu && chmod +x /opt/qingliu/qingliu
  rm -rf /opt/qingliu/frontend/dist.n && mkdir -p /opt/qingliu/frontend/dist.n
  cp -a /tmp/qd/. /opt/qingliu/frontend/dist.n/
  rm -rf /opt/qingliu/frontend/dist && mv /opt/qingliu/frontend/dist.n /opt/qingliu/frontend/dist
  systemctl start qingliu.service
  sleep 5 && systemctl is-active qingliu.service
  curl -sf -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8787/health
'
```

> `cp` 覆盖正在运行的二进制会报 `Text file busy`，**必须先 stop**。

## 四、回滚

```bash
ssh root@115.191.68.41 '
  TS=<备份时间戳>
  systemctl stop qingliu.service
  cp /opt/qingliu/qingliu.bak-$TS /opt/qingliu/qingliu
  rm -rf /opt/qingliu/frontend/dist
  cp -a /opt/qingliu/frontend/dist.bak-$TS /opt/qingliu/frontend/dist
  systemctl start qingliu.service
'
```

备份命名：`qingliu.bak-YYYYMMDD-HHMMSS`、`frontend/dist.bak-YYYYMMDD-HHMMSS`，各保留最新一份。

## 六、后端（不加班）部署

后端独立部署，**先后端、后清流**（清流依赖后端的 Responses 行为）。

```bash
cd ../不加班智能团后端
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 \
  go build -trimpath -ldflags="-s -w" -o /tmp/be.bin ./cmd/server

scp -i ~/.ssh/no996_prod_ed25519 /tmp/be.bin root@115.191.68.41:/tmp/be.bin
ssh root@115.191.68.41 '
  TS=$(date +%Y%m%d-%H%M%S)
  cp /opt/no996-backend/bin/server /opt/no996-backend/bin/server.bak-$TS
  systemctl stop no996-backend.service
  cp /tmp/be.bin /opt/no996-backend/bin/server
  chmod +x /opt/no996-backend/bin/server
  chown no996:no996 /opt/no996-backend/bin/server
  systemctl start no996-backend.service
  sleep 6 && systemctl is-active no996-backend.service
  curl -sf -o /dev/null -w "%{http_code}\n" https://worker.bujiaban.top/health/live
'
```

## 七、临时验证环境（用完即删）

确实需要在清流侧完全隔离地验证时，可以临时起一套，**验证完必须删干净**，避免长期维护两套：

```bash
# 起（端口 8789 / 库 qingliu_test / 域名 qingliu-test.bujiaban.top）
mysql -uroot -e "CREATE DATABASE IF NOT EXISTS qingliu_test CHARACTER SET utf8mb4;"
mkdir -p /opt/qingliu-test /etc/qingliu-test /var/lib/qingliu-test
sed -e 's|/qingliu?|/qingliu_test?|' -e 's|^LISTEN_ADDR=.*|LISTEN_ADDR=127.0.0.1:8789|' \
    -e 's|^DATA_DIR=.*|DATA_DIR=/var/lib/qingliu-test|' \
    -e 's|^STATIC_DIR=.*|STATIC_DIR=/opt/qingliu-test/frontend/dist|' \
    -e 's|^PUBLIC_ORIGIN=.*|PUBLIC_ORIGIN=https://qingliu-test.bujiaban.top|' \
    /etc/qingliu/qingliu.env > /etc/qingliu-test/qingliu-test.env
# …建 systemd unit 与 nginx server 块（参考生产配置），起服务验证…

# 删（一步都不能漏，否则会留着无用服务和证书）
systemctl stop qingliu-test.service; systemctl disable qingliu-test.service
rm -f /etc/systemd/system/qingliu-test.service
rm -f /etc/systemd/system/multi-user.target.wants/qingliu-test.service
systemctl daemon-reload
rm -f /etc/nginx/sites-enabled/qingliu-test.bujiaban.top.conf
rm -f /etc/nginx/sites-available/qingliu-test.bujiaban.top.conf
nginx -t && systemctl reload nginx
certbot delete --cert-name qingliu-test.bujiaban.top --non-interactive
rm -rf /opt/qingliu-test /etc/qingliu-test /var/lib/qingliu-test
mysql -uroot -e "DROP DATABASE IF EXISTS qingliu_test;"
```

## 八、常见问题

| 现象 | 原因 | 处置 |
| --- | --- | --- |
| `Text file busy` | 覆盖正在运行的二进制 | 先 `systemctl stop` |
| `bind: address already in use` | 端口被占 | `ss -lntp \| grep <端口>` 查占用者，改 env 的 `LISTEN_ADDR` |
| 登录提示"对接凭据失效" | 服务凭据过期/错 | 检查 `/etc/qingliu/qingliu.env` 的 `WORKBENCH_SERVICE_SECRET` |
| 502 | 后端没起来 | `journalctl -u qingliu.service -n 50` |
| AI 提取超时 | 后端推理慢或超时设置过小 | 看 `journalctl` 是否有 `context deadline exceeded`；确认后端在线 |
