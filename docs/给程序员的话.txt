这个包是清流网页交付版，已完整迁移为 Go + React + MySQL。

请复用现有 MySQL 和 HTTPS 反向代理，不要另外起 PostgreSQL、Redis 或消息队列。React静态文件、Linux amd64/arm64二进制都已打包，服务器不需要Python或Node服务；PDF/OCR使用Linux命令行工具，Dockerfile已列好依赖。

服务器按8核4GB共享环境做了保守限制：一个Go进程、单后台执行器、MySQL连接池最多8、容器2CPU/1GB。请结合现有服务实际占用观察峰值内存；不要按8核直接开8路识别。

部署前请先看 README.md 和 docs/部署与交接.md。需要你配置现有MySQL专用库/用户、真实HTTPS域名、独立随机VAULT_KEY；初始化管理员用服务器CLI，不是网页开放注册。当前没有AI调用，不需要配置API中转。

只缓存带哈希的网页静态资源，客户资料和报告不做浏览器持久缓存。数据库与文件卷、VAULT_KEY须按说明一起受控备份，密钥另存。

包里不包含真实客户资料、旧SQLite、密码或密钥。现有本地档案仍在原项目，尚未自动迁移到新库。若本次上线要带历史档案，请先安排专项迁移和对账，不能把SQLite直接当MySQL导入。

部署后先用samples/synthetic.csv走完上传、归属、复核、报告下载，再抽查你们实际使用的银行版式和团队权限。扫描征信的OCR只提供待核对文字，不自动给贷款结论。所有报告仅供内部初筛参考。
