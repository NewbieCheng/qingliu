# 09 · 路线图

## P0 稳定性

- 异地备份（对象存储/另一台机）+ 备份加密
- 服务存活、磁盘、备份失败告警
- 支付回调/退款与订单状态对账
- 真实银行/征信版式验收清单

## P1 体验

- 本地 Vite proxy，缩短前后端联调路径
- 客户底稿的键盘/批量核对效率
- 登录页/移动端持续视觉回归
- 报告模板可配置（仍保持快照与审计）

## P2 工程

- 数据库版本化 migration 工具
- 前端单测（Toast/路由/订单恢复）
- Go 集成测试在 CI 的独立 MySQL
- 访问日志脱敏与集中检索

## 不做

- 不做自动贷款审批/授信结论
- 不承诺所有银行版式自动识别
- 不在浏览器保存模型 Key/支付签名
- 不为单机任务引入 Redis/消息队列/微服务
