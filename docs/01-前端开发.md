# 01 · 前端开发

## 1. 技术栈与入口

- React 19.2、Vite 7、原生 CSS（无组件库）
- `frontend/index.html` 挂载 `#root`，`frontend/src/main.jsx` 是入口
- 构建：`npm ci --ignore-scripts && npm run build`，产物在 `frontend/dist`
- 开发服务器：`npm run dev`（127.0.0.1），当前没有 Vite API 代理；调接口时建议用 `npm run build` 后由 Go 同源提供，或在本地加 proxy 到 8787

## 2. 路由

`src/router.jsx` 提供：

- `usePathname()`：基于 `history.pushState`
- `navigate(path)`：派发 `ql:navigate` 自定义事件
- `<Link>`：客户端跳转
- `useLinkInterceptor()`：拦截站内 `<a>`，避免整页刷新

支持路径：`/`、`/login`、`/clients/:cid`、`/recharge`、`/profile`、`/admin`。新增页面时同时改 `router` 白名单和 `WorkspaceShell` 的导航。

**不要**在内部链接上恢复 `window.location.href`；这会造成白屏和登录态/滚动丢失。

## 3. Shell 与布局

`src/shell.jsx`：

- 侧边栏 `aside.rail`：品牌 Logo、工作区/账户/管理分组、导航图标、底部账号
- 顶栏 `.topbar`：侧栏收缩（左）、标题/说明、顶栏收缩（右）、账户/退出
- 移动端：`@media(max-width:680px)` 下侧边栏变为顶部横向导航，正文全宽
- 收缩状态持久化在 `localStorage`；图标全部 SVG

布局令牌在 `style.css`：侧栏 `232/68`、顶栏 `48/34`、内容最大宽 `1120px`。改密度优先改变量，不要在页面里写死大间距。

## 4. 登录页

`main.jsx` 的 `!user` 分支渲染 `.login-page`：

- 左：深松绿品牌区、Logo、主张、留痕说明
- 右：账号/密码、密码显隐、记住账号、管理员协助提示
- `LoginPassword` 组件管理显隐；`rememberedUser` 从 `localStorage["ql.login.username"]` 读取
- 登录成功走 `Form` 的 Toast，然后 `navigate("/")`
- 移动端隐藏左侧品牌区，显示 `qingliu-logo.svg`

账号由工作台统一管理；忘记密码联系管理员。不要在登录页伪造注册、邮箱验证码等后端不存在的入口。

## 5. 页面

### 客户列表 `/`
`Clients`：客户卡片/表格、创建客户、状态；点击进入 `/clients/:cid`。

### 客户底稿 `/clients/:cid`
`Case`：

- 页头：返回、客户名、创建时间、状态、资料数/交易数
- 四步步骤条：上传 → 确认归属 → 核对疑点 → 查看报告
- 上传：拖拽/选择、批次限制、扫描征信本地 OCR 开关
- 归属/覆盖范围/规则
- 交易核对：筛选、疑点、原页对照、标记
- 复核/提交/报告下载
- 可折叠区块的 chevron 使用 CSS data-URI SVG，不依赖原生 `<details>` 三角

### 充值 `/recharge`
`RechargePage` + `account.jsx`：

- 套餐卡（来自 `/api/billing/skus`）
- 创建/恢复待支付订单
- 二维码、有效期、剩余时间、继续支付
- 最近订单表、余额/积分/账本

### 账户 `/profile`
`ProfilePage`：工作台绑定信息、改密入口、退出。

### 管理 `/admin`
`Admin`：账号创建/停用、客户授权；仅管理员可见。

## 6. Toast

`src/toast.jsx`：

```js
import { toast } from "./toast";
toast("已保存", "success");
toast("保存失败", "error");
```

- 最多 3 条，自动消失
- `ql:toast` 事件驱动，`ToastHost` 在根节点
- 页面跳转时清空，避免登录 Toast 跟到下一页
- 表单 `Form` 的 `success` 默认“已保存”，失败走 error Toast；不要恢复 `.success` / `.error` 内联提示

## 7. 品牌与图标

Logo 包在 `frontend/public/qingliu-*.svg`：

- `qingliu-logo.svg`：浅色横版（登录、移动端）
- `qingliu-logo-dark.svg`：深色横版（侧栏）
- `qingliu-app-icon.svg`：收起态/ favicon
- `qingliu-icon.svg`、`qingliu-icon-mono.svg`：备用图形

Go 静态文件路由除 `/assets/` 外还显式允许 `.svg`；新增根目录静态资源时不要假设 Nginx 会直接吐，检查 `server/main.go` 的静态分支。

## 8. 修改清单

1. 改组件/样式 → `npm run build`
2. 需要生产 → 同步 `frontend/dist` 和 Go 二进制
3. 浏览器检查：登录、客户底稿、充值二维码、移动端 390px、无 console error
