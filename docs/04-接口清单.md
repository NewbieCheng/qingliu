# 04 · 接口清单

所有接口同源，默认 JSON。写请求需带会话 Cookie 和 `X-CSRF-Token`（从 `/api/me` 获取）。业务响应 `no-store`。

## 公共

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/health` | 真实 ping 数据库，ok 才算健康 |
| POST | `/api/login` | 工作台 service login 优先，本地密码兜底 |
| GET | `/api/me` | 当前用户、角色、工作台绑定、csrf |
| POST | `/api/logout` | 退出并删会话 |
| POST | `/api/password` | 修改本地密码，撤销其他会话 |

## 计费代理（转发工作台后台）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/billing/skus` | 青流可用套餐 |
| POST | `/api/billing/orders` | 创建/恢复待支付订单 |
| GET | `/api/billing/orders` | 最近订单 |
| GET | `/api/billing/orders/{order_no}` | 单笔订单（二维码/状态） |
| GET | `/api/billing/balance` | 积分余额 |
| GET | `/api/billing/ledgers` | 积分账本 |

清流不直接写支付表；订单在 `WORKBENCH_BASE_URL` 指向的工作台库。

## 客户与底稿

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/clients` | 当前用户可见客户 |
| POST | `/api/clients` | 新建客户 |
| GET | `/api/clients/{cid}` | 底稿数据（可按来源/日期过滤） |
| POST | `/api/clients/{cid}/upload` | 上传资料（multipart） |
| POST | `/api/clients/{cid}/ownership` | 确认归属 |
| POST | `/api/clients/{cid}/coverage` | 纳入范围/期间 |
| POST | `/api/clients/{cid}/rules` | 规则/阈值 |
| POST | `/api/clients/{cid}/review` | 逐笔核对标记 |
| GET | `/api/clients/{cid}/transaction/{tid}` | 交易详情 |
| GET | `/api/clients/{cid}/original/{did}/{page}` | PDF 原页 |
| POST | `/api/clients/{cid}/submit` | 提交复核 |
| POST | `/api/clients/{cid}/report` | 生成报告 |
| GET | `/api/clients/{cid}/reports/{rid}/{file}` | 下载报告 |
| POST | `/api/clients/{cid}/retry/{jid}` | 重试任务 |
| GET | `/api/clients/{cid}/jobs` | 任务状态 |
| GET/POST | `/api/clients/{cid}/ai-analysis` | AI 文档分析 |

## 管理

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/admin` | 用户/客户/授权总览 |
| POST | `/api/admin/users` | 创建用户 |
| POST | `/api/admin/users/{uid}/toggle` | 停用/启用 |
| POST | `/api/clients/{cid}/grant` | 授权/取消授权 |

## 上游工作台接口（清流调用）

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| POST | `/api/v1/service/auth/login` | service login |
| POST | `/api/v1/auth/refresh` | 刷新 token |
| GET | `/api/v1/payment/skus?service_code=qingliu` | 套餐 |
| POST | `/api/v1/payment/orders` | 下单 |
| GET | `/api/v1/payment/orders...` | 订单 |
| GET | `/api/v1/payment/balance` / `ledgers` | 余额/账本 |

具体字段以工作台仓库的 `api/openapi/openapi.yaml` 和 `web/admin/src/pages/PackagesPage.tsx` 为准；本文档只记录清流侧调用面。
