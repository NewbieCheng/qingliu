# 10 · 本地开发与测试

## 依赖

- Node 22.12+
- Go 1.26+
- MySQL 8.0+（本地独立库）
- Linux 侧解析依赖（生产）：`poppler-utils`、`poppler-data`、`mupdf-tools`、`tesseract-ocr`、`tesseract-ocr-chi-sim`

## 前端

```bash
cd frontend
npm ci --ignore-scripts
npm run build
npm run dev        # http://127.0.0.1:5173
```

当前没有 Vite proxy；`npm run dev` 只适合纯样式/组件调试。需要真实 API 时用 `npm run build`，由 Go 在 8787 同源提供，或在 `vite.config.js` 加 `/api`、`/health` proxy 到 8787。

## 后端

```bash
cd server
go test ./...
go vet ./...
```

本地跑服务：

```bash
export MYSQL_DSN='qingliu:pass@tcp(127.0.0.1:3306)/qingliu?charset=utf8mb4'
export PUBLIC_ORIGIN='http://127.0.0.1:8787'
export VAULT_KEY="$(openssl rand -hex 32)"
export DATA_DIR='/tmp/qingliu-data'
export STATIC_DIR='../frontend/dist'
export PDF_FONT='../fonts/NotoSansSC.ttf'
export LISTEN_ADDR='127.0.0.1:8787'
./bin/qingliu-amd64 init-admin
./bin/qingliu-amd64
curl -fsS http://127.0.0.1:8787/health
```

本地不要用生产 `VAULT_KEY`；不要连生产库。

## 集成测试

```bash
MYSQL_DSN='qingliu_test:...@tcp(127.0.0.1:3306)/qingliu_test?charset=utf8mb4' PDF_FONT=../fonts/NotoSansSC.ttf go test -v ./...
```

无 MySQL 时集成测试会跳过；跳过不等于通过。

## 浏览器回归

1. 登录 → 客户列表
2. 新建客户 → 上传 `samples/synthetic.csv`
3. 确认归属/期间 → 核对疑点 → 草稿 → 提交
4. 报告下载（PDF/Excel/HTML）
5. 充值页：套餐、下单、二维码、倒计时、刷新恢复
6. 移动端 390px：导航、底稿、表单无横向溢出
7. Console 无 error；网络请求无 4xx/5xx 非预期

## 构建交付

```bash
bash deploy/build.sh
```

会跑前端构建 + Go 测试/vet + amd64/arm64 二进制。发布前确保 `frontend/dist` 与二进制来自同一次构建。
