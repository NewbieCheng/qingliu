# 10 · 本地开发与测试

## 依赖

Node 22.12+、pnpm 11+、Go 1.26+、MySQL 8.0+（本地独立库）。生产 Linux 侧另需 `poppler-utils`、`poppler-data`、`mupdf-tools`、`tesseract-ocr`、`tesseract-ocr-chi-sim`。

## 前端

```bash
cd frontend
pnpm install --frozen-lockfile
pnpm build
pnpm dev        # http://127.0.0.1:5173
```

`vite.config.js` 默认把 `/api`、`/health` 代理到**本机清流** `http://127.0.0.1:8787`（`strictPort`，端口固定 5173）。本机全链路：

1. 工作台 API `http://127.0.0.1:8080`（另一仓库，`DB_DSN` 指向本机 `intelligent_team`）
2. 清流 Go `http://127.0.0.1:8787`（根目录 `.env`，`WORKBENCH_BASE_URL=http://127.0.0.1:8080`）
3. 前端 `pnpm dev` → `http://127.0.0.1:5173`

本地写操作会打到本机库（可从生产同步），不要误以为还在写生产。

**直连生产只读排查**：把 `vite.config.js` 的 `target` 改成 `https://qingliu.bujiaban.top`，并恢复 `Origin`/`Referer` 改写与响应 `Set-Cookie` 的 `Secure` 剥离，否则本地登录/保存会 403、Cookie 存不住。换环境后必须**重新登录**。

**本地登录预填**：`frontend/.env.local` 的 `VITE_DEV_LOGIN_USERNAME` / `VITE_DEV_LOGIN_PASSWORD` 只在 `pnpm dev`（`import.meta.env.DEV`）时填进表单，生产构建为空；该文件命中 `.gitignore`，不要提交。

## 后端

本机 go-build 缓存可能不可写，把缓存指到工作区内：

```bash
cd server
GOCACHE=$PWD/.gocache GOTMPDIR=$PWD/.gotmp GOPATH=$PWD/.gopath \
  TMP=$PWD/.gotmp TEMP=$PWD/.gotmp go test ./... && go vet ./...
```

本地跑服务：

```bash
export MYSQL_DSN='qingliu:pass@tcp(127.0.0.1:3306)/qingliu?charset=utf8mb4'
export PUBLIC_ORIGIN='http://127.0.0.1:8787'
export VAULT_KEY="$(openssl rand -hex 32)"
export DATA_DIR='/tmp/qingliu-data'
export STATIC_DIR='../frontend/dist'
export PDF_FONT='../fonts/NotoSansSC.ttf'
export LISTEN_ADDR='127.0.0.1:8787'
export QINGLIU_ALLOW_LOCAL_LOGIN=1        # 没有工作台时用本地密码登录
ADMIN_USERNAME=admin ADMIN_PASSWORD='<10至72字节>' ./bin/qingliu-amd64 init-admin
./bin/qingliu-amd64
curl -fsS http://127.0.0.1:8787/health
```

本地不要用生产 `VAULT_KEY`；不要连生产库。

## 检查与测试

```bash
cd frontend
pnpm lint          # ESLint
pnpm check:arch    # 目录边界
pnpm test          # Vitest
pnpm check         # lint + 边界 + test + build
pnpm smoke         # Playwright 冒烟（mock API、路由、390px）
```

`pnpm smoke` 需要本机 Playwright Chromium；路径不同时改 `frontend/scripts/smoke.mjs` 的 `executablePath`。它不能替代真实接口回归。

集成测试需要独立 MySQL 测试库，未设 `MYSQL_DSN` 时 `t.Skip`——跳过不等于通过：

```bash
MYSQL_DSN='qingliu_test:...@tcp(127.0.0.1:3306)/qingliu_test?charset=utf8mb4' \
PDF_FONT=../fonts/NotoSansSC.ttf go test -v ./...
```

## 浏览器回归

1. 登录 → 客户列表
2. 新建客户 → 上传 `samples/synthetic.csv`
3. 确认归属/期间 → 核对疑点 → 草稿 → 提交
4. 报告下载（PDF/Excel/HTML）
5. 充值页：套餐、下单、二维码、倒计时、刷新恢复
6. 移动端 390px：导航、底稿、表单无横向溢出
7. Console 无 error；网络请求无非预期 4xx/5xx

## 构建交付

`bash deploy/build.sh` 会跑前端构建 + Go 测试/vet + amd64/arm64 二进制。发布前确保 `frontend/dist` 与二进制来自同一次构建。
