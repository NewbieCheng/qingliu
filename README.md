# 清流 Qingliu · 客户资料与流水初筛工作台

> **清流独立开发工作区。** 先读 [`AGENTS.md`](AGENTS.md) 与 [`docs/00-项目总览.md`](docs/00-项目总览.md)。服务器、账号与密钥在本地 `.secrets/`（不提交）。

清流是「今天不加班」旗下的内部工作台：把客户资料、银行流水、征信扫描件和人工复核记录收在一个可追溯的底稿里，生成内部初筛报告。它不替代银行审批，也不自动给出贷款资格结论。

## 技术栈

- 前端：React 19 + Vite，静态构建后由 Go 同源提供
- 后端：Go 标准库 HTTP 单进程，MySQL 8，进程内单执行器
- 文件：Poppler/MuPDF 文本提取，Tesseract OCR 仅给候选；报告 PDF/Excel/HTML 由 Go 生成
- 身份与计费：工作台 service login + 工作台计费代理；本地密码仅作应急兜底

## 快速开始

```bash
# 1. 构建（开发机，需 Node 22.12+、Go 1.26+、pnpm）
bash deploy/build.sh

# 2. 准备环境文件（参考 .env.example；真实值放 .secrets 或服务器环境文件）
cp .env.example .env

# 3. 首次部署初始化第一个管理员
ADMIN_USERNAME=admin ADMIN_PASSWORD='<10至72字节>' ./bin/qingliu-amd64 init-admin

# 4. 本地运行
./bin/qingliu-amd64
curl -fsS http://127.0.0.1:8787/health
```

生产使用 systemd + 宿主机 MySQL；见 [`docs/05-部署与运维.md`](docs/05-部署与运维.md)。
